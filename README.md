# jikasei

![jikasei](preview.png?v=3)

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0 改造。纯静态前端，只读 hub 的公开接口，
国旗与图标资源都自带。

## 安装

首次安装需从 Releases 下载 theme.tar.gz 上传至探针后台，后续可在主题卡片上点击从 GitHub 更新。

## 预览

![节点地球](preview-globe.png?v=3)

列表页顶部那颗正射投影的地球（默认开着）：

- **地球**：海岸线数据自带（79 环 1483 点），不连任何外部服务；可拖拽旋转，没人碰时自己慢慢转，
  钉住某个地区后停下；系统开了「减弱动态效果」则不转。
- **点击**：点一枚针、或两侧地区标签里的任意一行，＝打开那台机器的整页详情（多台共用一枚针时打开其中第一台）；从它们上面拖拽仍然是转地球。
- **针**：小队一台一枚（标签写机器名）；整队 ≥30 台、或同一地区 ≥5 台时聚成一枚带台数的针
  （标签写地区名）。落点按国家算，名字或分组里认得出城市就按城市。
- **地区名**：能认到城市写城市（城市级带国家码，如 `US · Phoenix`）；认不出写**国家名**
  （`United States`；HK/SG/MO 这类城市国家永远给城名）。认不出国家的机器不上地球、也不进
  地区列表（但照算在「全部」里）。
- **地区列表**：按地区分组与台数；点一行＝地球飞过去并钉住，下面那张列表只留该地区的机器；
  再点一次、或点「全部」＝取消筛选、继续自转。切分组标签时地球与地区列表跟着变。
- **窄屏**：与桌面同一档（海岸线、扫掠、连线都在）；拖动只接管横向，竖划仍然是滚页面。
- **顶栏入口图标（自动探测，没有设置项）**：本站 `/chicken/` 上装了那座 3D 小鸡农场才出现，
  没装就什么都不显示、也不占位。

整页详情（点开任意一台）里那张延迟图：

- **滚轮＝收放纵向范围**（光标在图上时，页面不跟着滚）：以光标压着的那个值为锚点；量程夹在
  1ms 与「1000ms／数据顶 × 2（取大）」之间。
- **左键上下拖＝平移这段范围**（整段一起停，下沿不越 0）；**双击、或右上角那枚「重置」＝
  回到自动量程**（滚轮或拖动过后才会出现这枚按钮）。
- 只在整页详情开：列表里紧凑展开的那张小图不抢滚轮（要留给翻列表）。
- **时间量程**按 hub 的保留天数生成：1／6／24 小时一直都在，够得着才多出 7 天、30 天与保留
  天数本身（最多六枚）。

## 访客自己换卡片形态

顶栏那枚方形图标（列表页才有）点开是六档：**经典 / 简约 / 延迟 / 详细 / 宽卡 / 紧凑**，选中的
打勾、站长在后台设的那档标「默认」。选完立刻生效、刷新还记得（只记在访客自己的浏览器里）。
点别处或按 `Esc` 收起。

## 关于备注

备注在 hub 后台的节点里填，有**公开**（写给访客，hub ≥ 1.3.2，单行 ≤100 字）与**私有**（写给
自己，只下发给登录的管理员）两处；半角 `,` 与全角 `，` 都算分隔、一枚一枚各自成小卡片，私有那条
按换行也能拆。显示时两处合成一串：私有在前（带锁 + 描边，只有登录的自己看得到）、公有在后；
摊在哪儿由「备注显示位置」决定。

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不留副本）。
「地球」「明暗」「卡片形态」三处，访客都能在顶栏自己覆盖，只记在他自己的浏览器里；选回与站长
相同的那档＝重新跟着站长的设置走。

**站点图标不在这一页**：hub 1.4.0 起由面板的「设置 → 站点图标」管（换主题也保留），主题自带的
那份只在没设图标时兜底。

| 分组 | 设置项 | 默认 | 说明 |
|---|---|---|---|
| 列表与卡片 | 节点地球 | 开 | 列表页顶部那颗会自转的地球（观感与交互见「预览」）；关掉＝整块不渲染，顶栏那枚开关也一起收起。 |
|  | 列表页顶部 | 两个都显示·概览卡片价值版 | 分组标签行与概览卡片行的六种组合：都不显示／只分组标签／只概览卡片（原版或价值版）／两个都显示（原版或价值版，默认）。概览卡片＝那行统计卡片，数字跟着分组标签那档走；价值版把前两张换成「月度预算」与「剩余价值」（按汇率折人民币：每天自动更新、拉不到用内置兜底表，所以标 ≈；口径、汇率与取价日期在悬停提示里；买断与没填价的不计）。 |
|  | 卡片形态 | 详细 | 访客默认看到的档：**经典**（2×2 四格，延迟收右上角浮层）／**简约**（底行两段、不带延迟）／**延迟**（简约同款 + 三网延迟）／**详细**（再加时长、价格、到期）／**宽卡**（一行两张：四格读数 + 上传下载 + 总流量条）／**紧凑**（一行一台表格，点一行就地展开延迟图）；长相见「预览」画廊。 |
| 节点信息 | 备注显示位置 | 卡片与详情页都显示 | 四选一：都显示／只卡片／只详情／都不显示（hub 里填了也不摊）。备注的写法见「关于备注」。 |
|  | 显示的延迟线路 | 空（自动） | 卡片「三网延迟」显示哪几条线路：一行一个 ping 任务名（最多三条），留空按后台顺序取前三条；对不上的名字跳过。 |
| 外观 | 主题模式 | 随系统设置 | 整站明暗四选一：随系统／随北京时间自动（19:00–07:00 暗色、固定 UTC+8，页面开着跨过切换点会自己换）／亮色／暗色。 |
