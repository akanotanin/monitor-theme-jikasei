# jikasei

极简探针（[Monitor](https://github.com/monitor-probe/monitor)）的第三方主题，源码基于上游默认主题
`monitor-theme-default` v1.1.0（React + Vite + shadcn/ui）改造。纯静态前端，只读 hub 的公开接口，
国旗与图标资源都自带。

## 特性

- **顶栏**：站点名左边一枚圆形站标（默认 `/site-icon.png`，可在后台换成任意地址，同时作为浏览器标签页、
  书签与手机桌面的图标）；「进入后台」由「扳手 + 文字」收成一枚图标按钮，文字挪进 `title` / `aria-label`；
  页面宽度上限 1280px。
- **养鸡场入口**：顶栏一枚小鸟图标，默认自动认本站的 `/chicken/`——装了才出现，没装则整枚不渲染；也可以
  在后台填地址指向别处，或用开关关掉。
- **列表页**：去掉顶部那条汇总统计，卡片只留一行身份（国旗 + 名称）、四个环形用量与底部的上下行速率和总量，
  没有系统 / 虚拟化 / 架构那一行，也没有状态与到期徽章（详情页里写得更全）。
- **卡片形态**：默认「经典」——就是上面那种两行网络数字的紧凑卡片，访客端一次延迟请求都不发；后台切
  「详细」后网络合成一行（总量 · 速率各一组），下方按线路挂三网延迟（线路名 / 最新延迟 / 一小时走势 /
  丢包率），可指定显示哪几条、名字照抄后台的 ping 任务名。
- **国旗**：主题自带的 258 面静态 SVG（`/flags/<CC>.svg`，按 ISO 3166-1 alpha-2 命名），按国家码现取一张，
  访客只下载页面上真正出现的那几面；取不到的退回文字徽标。
- **详情页**：标题行只留国旗 + 名称；信息项最后一格由「续费」换成「在线时间」；去掉 agent 版本徽章。
- **图表**：九色延迟调色板（亮色压亮度、深色抬亮度），资源图用固定语义色（CPU 蓝 / 内存紫 / 下行绿 /
  上行橙 / 硬盘青）；延迟图不用图表库的默认 tooltip，改成自绘面板——最慢的线路排前面，超时的保留并标
  「无响应」，有丢包的缀一段丢包率，窄屏只列前 5 条、其余折成「另有 N 条」。
- **标签页标题**：由站名驱动，详情页按「节点名 · 站名」写；刷新时标题不跳变（`index.html` 的静态
  `<title>` 与 `public/jikasei-title-probe.js` 配合）。
- **分组标签行**：默认关闭，节点按分组顺序平铺成一整列；需要「全部 / 各组 / 未分组」那一行时在后台打开。

## 安装

hub 的「主题」页上传 `theme.tar.gz`，或点面板上那颗指向本仓库的「更新」（按版本号比对，新版本需已发
Release）。也可以直接把目录放进 hub 的 `--themes` 位置，无需重启：

```text
<themes-dir>/jikasei/
├── theme.json
├── preview.png
└── dist/
```

## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不落副本）：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 站点图标 | `/site-icon.png` | 顶栏那枚 32px 圆形站标的地址，同时也是浏览器标签页／书签／手机桌面快捷方式的图标。填完整网址或站内路径；取不到就回落到主题自带那张。 |
| 显示养鸡场入口 | 开 | 顶栏那枚小鸟图标的开关。关掉后相关的探测与渲染都不再发生。 |
| 养鸡场地址 | 空（自动） | 留空 = 自动认本站的 `/chicken/`；想固定指向别处（同域路径或完整网址）就填地址。 |
| 显示分组标签行 | 关 | 列表页顶部那行分组标签（全部 / 各组 / 未分组）的开关。节点本来就没有分组时，这一行无论如何都不显示。 |
| 卡片形态 | 经典 | 卡片长什么样：「经典」网络速率与总量分两行、不含延迟（也就不去拉延迟数据）；「详细」网络合成一行、下方带三网延迟。 |
| 显示的延迟线路 | 空（自动） | 卡片「三网延迟」里显示哪几条线路。每行一个 ping 任务名，最多三个，按填写的顺序显示；留空则按后台顺序自动显示前几条。名字对不上（改过名、任务删了）那一行跳过。仅在「详细」形态下生效。 |

判据是内容而不是状态码：`/chicken/` 装了和没装都会返回 200（hub 对未知路径回落 `index.html`），所以主题
问的是 `GET /chicken/api/nodes`，回 JSON 才显示图标；这次探测等站点设置取回来之后才发，站长填了地址或关掉
开关的站一次都不会发。六项设置只走 `GET` / `PUT /api/themes/jikasei/config`，访客自己的深浅色偏好仍走
localStorage。

`theme.json` 的 `config` 声明表单，`src/lib/theme-config.ts` 的 `DEFAULTS` 是页面兜底，两处必须逐项一致，
`npm run check` 在打包前核对（`npm run package` 与 CI 都会调）。

## 开发

```bash
npm ci
npm run build && npm run lint && npm test   # 构建产物在 dist/
MONITOR_HUB=https://hub.example.com npm run dev   # 不设则代理至 http://127.0.0.1:9911
npm run package                             # 产出 release/theme.tar.gz + .sha256
```

主题只能依赖同源接口（`/api/me`、`/api/nodes`、`/api/nodes/{id}/metrics`、`/api/ws` 与
`/api/themes/jikasei/config`），约定见文档站的[主题开发](https://monitor-document.pages.dev/dev/theme)。
`theme.json` 的 `name`/`short`/`description`/`version`/`author`/`url` 六个字段都要写，`config` 可选。
详情页路由是 `/node/{id}`，hub 会回落到主题的 `index.html`；hub 前面若有按路径做白名单的反代或 WAF，
记得放行这个前缀。**版本号一动就要打新 tag 发 Release**：面板的「更新」按版本号比对。

验收脚本都在 `tools/`（本机静态伺服 `dist/` + 桩接口，不需要真 hub、不需要密码）：
`shots.mjs` 一键拍七种机位并回报国旗／入口／站标是否在位，`verify_icons.mjs` 验图标的兜底顺序，
`verify_farm_entry.mjs` 验入口的开合组合与探测次数，`verify_title.mjs` 录每一次 `<title>` 变化，
`verify_settings_dialog.mjs` 用 CDP 打桩确认「主题设置」里那几项都画得出来。
