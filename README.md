## 主题设置

后台「主题」页的「主题设置」，改完对访客立即生效（值存在 hub 的站点配置里，访客端不落副本）：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 站点图标 | `/site-icon.png` | 顶栏那枚 32px 圆形站标的地址，同时也是浏览器标签页／书签／手机桌面快捷方式的图标。填完整网址或站内路径；取不到就回落到主题自带那张。 |
| 养鸡场入口 | 空（自动） | 顶栏那枚小鸟图标的去处，三种状态挤在一格里：留空 = 自动认本站 `/chicken/`（装了才显示）；填 `off` = 不显示入口（相关的探测与渲染都不再发生）；填地址 = 固定指向别处（同域路径或完整网址）。 |
| 列表页顶部 | 都不显示 | 列表页顶部显示什么，六选一：**都不显示**（默认）／**只显示分组标签**／**只显示概览卡片·原版**／**只显示概览卡片·价值版**／**两个都显示·概览卡片原版**／**两个都显示·概览卡片价值版**。分组标签 = 那一行「全部 / 各组 / 未分组」，节点本来就没有分组时无论如何都不显示；概览卡片 = 那行统计卡片，数据都取自节点列表本身、不多发请求，只有实时网速那张下面那条走势线画的是访客打开页面后的实时速率，刷新页面就从空的重新攒。原版是四张卡片各一块读数（节点在线数、最忙节点、今日与累计流量、全站实时网速）；月度预算剩余价值版把前两张各排两块读数——第一张是「月度预算」与「剩余价值」，第二张是「节点」与「最忙节点」（两块分居卡片两端）。**月度预算** = 各节点价格按计费周期摊到每月后相加；**剩余价值** = 已付但没用完的那一段（价格 × 剩余天数 ÷ 周期天数）；两者都按主题里写死的固定汇率折成人民币显示（因此写「≈」，口径与汇率在悬停提示里），一次性买断、没填价格、没有到期日的机器不计入。 |
| 卡片形态 | 简约 | 卡片长什么样：「经典」卡片底部是 2×2 四格——速率一行、总量一行（都是文字箭头 ↓ ↑，第一行用前景色、第二行弱化），上面一条分隔线，不含延迟（也就不去拉延迟数据）；「简约」把底部收成一行两段——左边实时速率、右边累计总量，读数窗另换一套视觉——表名改用前景色（附加信息仍弱化）、进度条压到 4px、底注降到 11px、名字加粗一档、读数格行距收紧，同样不含延迟；「延迟」底部与「简约」同一行两段、下方带三网延迟；「详细」在延迟之上再添在线时长、价格与到期；「紧凑」换成一行一台的表格（名称 / 系统 / 在线 / 剩余 / 价格 / 负载 / 网速 / CPU / 内存 / 硬盘 / 流量，列随屏宽收放、每个指标带一条细进度条），一屏能排下两三倍。**紧凑形态点一行就地展开**——展开行里挂的是那张带量程按钮与削峰开关的延迟图（不跳详情页），要去整页详情点展开行右上角的入口。量程按 hub 的**保留天数**生成：1 / 6 / 24 小时一直都在，够得着才多出 7 天、30 天与保留天数本身（最多六枚）；保留天数超过 7 天的窗口读的是 hub 的小时汇总，坐标轴只写到日。五种形态配色与读数口径一致，只有信息多少与排布不同。 |
| 备注的落点 | — | **公开备注**在**卡片上**看，**整页详情不摊它**（那一页只留规格与图表）。**「经典」「延迟」形态**——卡片右上角常驻一枚信息图标（20px，挂在标题行右端）：悬停（桌面）或点一下（手机）弹出浮层，里面是**在线时间 / 价格 / 到期**，写了备注就在最上面多一排小卡片；没写备注时这枚图标照样在（不然那三项在这两档上无处可看），卡片几何与写了备注时逐像素相同——浮层不占位。**「详细」形态**——备注挂在**标题行右端**（名字右边），卡片其余部分一个像素都不动：在线时长仍在第二行左侧、价格仍在右侧、第三枚读数盒下面仍是到期日；放不下就截断，整枚挂在悬停提示里，名字不受影响。**「紧凑」形态**——并排在展开行量程栏右端、「完整详情 ›」的左边（桌面），手机这一行放不下，收成同一位置的一枚小图标（点开是浮层，点别处或 Esc 收起）；两种都不新增行高。**「简约」形态**不显示备注、也不挂那枚图标。**私有备注**只在**整页详情**上摊（访客拿不到那个字段）：按探针原本的设定**整段展示**（保留换行、不做逗号拆分），块顶带一行「私有备注 · 仅自己可见」标记。 |

## 关于备注

备注由 hub 后台**按节点**填，主题这边**没有备注设置项**——两个字段都在节点编辑里：

1. **公开备注**（hub ≥ 1.3.2，单行 ≤100 字）——写给访客看的那条，随公开视图下发，匿名访客也拿得到；
2. **私有备注**（面板里的 placeholder 就是「仅管理员可见」）——只下发给登录的管理员，访客拿不到。

**公开备注**的写法：逗号分隔就是多枚，一枚一枚各自成小卡片（半角 `,` 与全角 `，` 都认，两侧空白
削掉、空片段丢掉）——与 1.15.x 那份清单逐字相同，从旧版迁过来不用改写。

**私有备注不拆**：按探针原本的设定**整段展示**（`whitespace-pre-wrap`，保留你自己分好的换行），
块顶带一行「私有备注 · 仅自己可见」标记——它是写给自己看的备忘，成段的说明拆开反而读不懂。

主题设置里留了一行说明指出这一点。


历史：1.15.x 及更早，备注写在主题设置里的「服务器备注」清单（每行 `服务器名=备注`）；**1.18.0 起彻底删掉**——备注只在 hub 后台维护一处。老站点配置里那份清单会留在 Hub 的
站点配置里没人读（无害），备注改在后台节点里填即可。
